# trife — Life Simulator

A dark, responsive life-simulation UI built with plain HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.

The app uses hash routes (`#overview`, `#timeline`, `#relationships`, `#career`, `#activities`, `#education`, `#assets`, and `#settings`) and stores the game state in `localStorage`.
